Bank Account Management System

A simple console-based Bank Account Management System developed in Java.
This project demonstrates core Java concepts such as Object-Oriented Programming (OOP), classes, objects, encapsulation, ArrayList, methods, loops, conditional statements, and switch-case.

Create a new bank account
View account details
Deposit money
Withdraw money
Check account balance
Display all accounts
Delete an account
Prevent duplicate account numbers
Validate deposit and withdrawal amounts
Check for insufficient balance

Technologies Used:
Java
Java Collections Framework
ArrayList
Scanner
Object-Oriented Programming

Project Classes

Account.java:
Represents an individual bank account.

It contains:
Account number
Account holder name
Account balance
Deposit functionality
Withdrawal functionality
Account information display

Bank.java:
Manages multiple bank accounts using an ArrayList.

It handles:
Creating accounts
Finding accounts
Depositing money
Withdrawing money
Checking balances
Displaying all accounts
Deleting accounts

Main.java:
Contains the main program and provides a menu-driven console interface for interacting with the banking system.
